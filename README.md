# OmniCommonTools

面向开发者的常用 Web 工具箱。首期工具包括：

- JSON 美化
- 文本 / JSON Diff
- 时间戳转换

## 本地开发

```bash
npm install
npm run dev
```

## 验证

```bash
npm test -- --run
npm run build
npm run e2e
```

## 路由

- `/`：全部工具
- `/favorites`：收藏
- `/tools/json-formatter`：JSON 美化
- `/tools/text-json-diff`：文本 / JSON Diff
- `/tools/timestamp-converter`：时间戳转换
- `/about`：关于
